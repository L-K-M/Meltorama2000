# Changelog

## 2.0.1

- Add a native macOS editor with SwiftUI inspectors, AppKit document windows,
  all twenty brushes, lenses, Fusion, crop, whole-photo effects, and GOOvies.
- Preserve Android project graphs and original photo bytes in editable Finder
  packages, with native undo, autosave, recovery, and PNG/JPEG/MP4/GIF export.
- Add self-contained Mac app packaging, English and Simplified Chinese
  resources, and native core, GPU, document, and interaction regression tests.
