Meltorama 2000 for macOS

Application source, warp shaders, sample artwork, and app icon: this repository,
released into the public domain under the Unlicense. See LICENSE.

The Mac icon is original imagegen artwork created for this project and edited
from that original into a colorful square. Its provenance and complete edit
prompt are included in IconProvenance.md.
No source photograph or third-party reference artwork is included in it.

The macOS application has no third-party runtime libraries, fonts, encoders,
or downloaded resources. It uses Apple's AppKit, SwiftUI, ImageIO, OpenGL,
AVFoundation, and the Swift standard library supplied by the operating system.
SF Symbols are displayed through Apple's system APIs under Apple's terms.

The Android application has its own dependency notices. Its runtime libraries
are not included in the macOS application.
